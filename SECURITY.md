# Security policy

## Reporting a security problem

Please **don't open a public issue** for a security problem, such as a leaked key or
password, or a bug that could harm someone running the code. Report it privately instead:
go to the repository's **Security** tab and choose **Report a vulnerability**. Only the
maintainer can see these reports.

## Sensitive archaeological information

Treat site locations the same way. If you think this repository, an issue, a pull request
or a comment exposes the location of a possible or unrecorded site, or a burial:

1. Don't repeat or link the location anywhere public.
2. Report it privately through **Security → Report a vulnerability** so it can be removed.

If you believe you've found a real site, report it to your state's archaeological site
files (in Georgia, the Georgia Archaeological Site File). If it might involve human
remains, contact local law enforcement as state law requires.

## Supported versions

Only the latest release is maintained.
