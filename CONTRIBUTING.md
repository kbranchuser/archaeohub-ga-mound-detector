# Contributing

Thanks for your interest. This is a small, focused project: a Georgia LiDAR mound
detector. Every change is reviewed by the maintainer, and pull requests that fall outside
the scope below will be closed. Please open an issue to discuss a change before you
spend time on it.

## Welcome

- Bug fixes in the existing scripts.
- Clearer documentation.
- Better or faster ways to prepare, train, evaluate or scan, with a short note on how you
  tested them.
- Test mounds or look-alikes from **already-published, public-land** sources, with the
  source cited.

## Not accepted

- **Coordinates or maps of possible or unrecorded sites**, including anything the
  detector flags. Never put these in code, issues, pull requests or comments.
- Site-file (DINAA or state site-file) coordinates, or data from private land.
- Large data files, rasters or model weights (weights are published as release assets).
- New features, apps, services, dependencies or GitHub Actions workflows that the project
  doesn't need.
- Unrelated refactors or reformatting.

## Found something that might be a real site?

Don't post it here. Report it to your state's archaeological site files (in Georgia, the
Georgia Archaeological Site File). If it might involve human remains, contact local law
enforcement as state law requires.
